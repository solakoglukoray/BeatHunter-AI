# tensorflow stays listed only for the retired EfficientNetB3 training path. It is

# --- Audio embedding (PANNs) ---
# PANNs (AudioSet-pretrained CNN) replaced the in-house EfficientNetB3 for
# classification and retrieval: 22.9x chance for artist against 16.7x for the classical
# MFCC baseline and 0.8x — below chance — for EfficientNetB3, all on the same held-out
# tracks. PyTorch has working Windows CUDA support, unlike TensorFlow, so this needs no
# WSL2. Weights (327 MB) are downloaded once to ~/panns_data; see audio_features.py for
# the command.
torch
panns-inference
